# EOS Task App - Frontend

Angular frontend for a small task-management application. The UI supports role-based task views, task search, pagination and sorting, user administration, task conversations, and notifications.

## Main Features

- Login and registration with client-side form validation
- Separate views for personal, assigned, and all tasks
- Task creation, updates, status changes, and deletion
- Server-side pagination, sorting, and task search
- Admin user management with role restrictions
- Task conversations with comments and notifications
- JWT authentication through an HTTP interceptor

## Tech Stack

- Angular
- TypeScript
- HTML and CSS
- RxJS
- REST API integration
